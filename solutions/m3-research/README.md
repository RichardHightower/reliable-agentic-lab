# Module 3 solution: research report loop

Locked title: Research Loops and MCP.

One live research assistant. Not a survey of servers.
Mimic of the Spillwave articles v3 pipeline. Output is a short report,
not a Medium article.

1. Research in a sub-agent. Perplexity if keyed, fixture otherwise.
2. Draft a report. Orchestrator gets a summary, not the dump.
3. Fact-check loop against a rubric. Checker has no write tools.
4. Style-guide enforcer. Deterministic em-dash strip, then rubric.
5. Exit on passing grade, max loops, or max budget.
