# Module 1 architecture

```
ready ticket
    -> copy starter CRM into work/
    -> Maker-shaped apply of scoped files
    -> hidden grader
    -> PR.md
```

Scoped files only:

- `app/dates.py`
- `app/models.py`
- `app/main.py`
- `app/templates/task_form.html`
- `app/templates/tasks.html`

The loop does not edit graders. It does not change ticket state.
It does not merge.
