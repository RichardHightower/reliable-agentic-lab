# Feature map

Loop Engineering plus Harness Engineering. Same CRM. New machinery each hour.

Do not survey seven production loops as labs. Name them in Module 4. Build one graph.

| Feature | Session that proves it | What the room actually sees |
|---|---|---|
| Trigger | 1 | Ready ticket on disk |
| Action | 1 | Implement due dates on a starter CRM copy |
| Verify | 1 | Hidden pytest. Fail then pass. |
| Memory outside the chat | 1 | Work copy plus PR body. Point back to 20 August. Do not rebuild second brain. |
| Human oversight | 1 | Human still merges. PR.md is the artifact. |
| One-shot failure: no contract | 1 bridge | Vague ticket would have been guessed |
| One-shot failure: no stop | 1 bridge | Model will keep editing |
| One-shot failure: context rot | 1 bridge | Whole repo in the window |
| Maker with scoped write tools | 2 | Can touch five CRM files. Cannot touch graders. |
| Checker with no write tools | 2 | Reads pytest. Never edits. |
| Spec as a testable contract | 2 | Ready ticket success criteria load as the rubric |
| Grader | 2 | Hidden due-date tests |
| Quality gate | 2 | pass, retry, escalate |
| Stop: pass | 2 | Grader green |
| Stop: max loops | 2 | Budget 3 |
| Stop: repeat failure | 2 | Same failed node ids twice |
| Orchestrator sees summaries | 2 | Not the whole diff |
| Local traces | 2 | `traces/last-loop.json` |
| Sub-agent tool scope | 2 | Deep Agents or Claude Agent SDK as the shape. Python owns the retry. |
| MCP tool contract | 3 | One server. Research. No merge. No deploy. |
| Research in a sub-agent | 3 | Orchestrator gets a summary |
| Cost accounting | 3 | Each call adds to the budget |
| Fact-check domain loop | 3 | Rubric. Editor writes. Checker does not. |
| Style-guide enforcer | 3 | Deterministic em-dash strip, then rubric |
| Sequential quality domains | 3 | FACT then STYLE |
| Fixture fallback | 3 | Perplexity key optional |
| Unattended trigger | 4 | Actions. Schedule or PR. Not a keystroke. |
| Durable state | 4 | ticket, branch, trace id, last score |
| Observability in production | 4 | If you cannot read the last score, you cannot debug at 2am |
| PR Fixer pattern | 4 | Failing PR to mergeable PR. Done-folder, live only if on time. |
| Swap the object | 4 | Keep the graph. Replace CRM tickets with their backlog. |

Session 1 is a loop that can run once.
Session 2 is that loop made repeatable.
Session 3 is the same graph on research, with MCP and two quality domains.
Session 4 is the same graph with no human at the keyboard.
