# If you fall behind

Nobody is graded here. Falling behind on one lab must not cost you the next one.

## Do this

1. Stop typing and watch Rick finish the build.
2. When he is done, run:

   ```bash
   git checkout done-m2
   ```

3. You now have a working ticket implementer and the harness. Continue with the next module.

## What you get

A reusable evaluation harness that plans, executes, verifies, and iterates.

## Coming back later

Put the empty stub back whenever you want to try it again:

```bash
git checkout main -- labs/m2-implementer
```

That restores this lab only. Everything you need is in `prompts/`, and
`loops/implementer.py, loops/rubric.py, and loops/gates.py` is the answer whenever you want it.
