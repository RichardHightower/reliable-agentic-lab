# If you fall behind

Nobody is graded here. Falling behind on one lab must not cost you the next one.

## Do this

1. Stop typing and watch Rick finish the build.
2. When he is done, run:

   ```bash
   git checkout done-m3
   ```

3. You now have a working research assistant over mcp. Continue with the next module.

## What you get

A working research assistant that cites what it retrieved.

## Coming back later

Put the empty stub back whenever you want to try it again:

```bash
git checkout main -- labs/m3-research
```

That restores this lab only. Everything you need is in `prompts/`, and
`loops/researcher.py, loops/research.py, and loops/brief.py` is the answer whenever you want it.
