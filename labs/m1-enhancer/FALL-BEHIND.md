# If you fall behind

Nobody is graded here. Falling behind on one lab must not cost you the next one.

## Do this

1. Stop typing and watch Rick finish the build.
2. When he is done, run:

   ```bash
   git checkout done-m1
   ```

3. You now have a working ticket enhancer. Continue with the next module.

## What you get

A working autonomous loop, running on your machine.

## Coming back later

Put the empty stub back whenever you want to try it again:

```bash
git checkout main -- labs/m1-enhancer
```

That restores this lab only. Everything you need is in `prompts/`, and
`loops/enhancer.py and loops/criteria.py` is the answer whenever you want it.
