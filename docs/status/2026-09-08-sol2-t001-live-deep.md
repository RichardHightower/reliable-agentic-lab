## Cap note

Spend came in above the $3.00 cap. Deep Agents has no per-query dollar
ceiling equivalent to the SDK's `max_budget_usd`: `budget_usd` (echoed
above) is applied and read correctly, but nothing stops a single
`agent.invoke()` call mid-flight once it has started. The recursion
limit is the only structural ceiling on one call, and 32 super-steps
still cost more than $3 here. This gap is proposal item one of #549.

## A defect found during this run, and the #549 fixes

The fixture clone (`work/northwind-field-crm`, outside this run's own
worktree) picked up two untracked, model-authored files during this
attempt: `tests/test_due_date.py` and `tests/test_due_dates.py`. The
#543 fix rooted the orchestrator's own `FilesystemBackend` and
`run_tests` tool at the worktree, but `roles.subagents_for` -- which
builds the actual write and read tools the test and code implementer

and never saw the worktree path. This gap is ticket #549, fixed on its
own branch and PR #552 (`subagents_for` now takes `cwd`, and
`build_agent` threads its own resolved path through), covered by an
offline test against the real `roles.subagents_for`, not a bypassing
fake.

by a live run. This trace's own run predates both #549 fixes. A
confirming live run, under a cap the code enforces, still needs to
